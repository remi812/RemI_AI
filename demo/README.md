# Автономная демонстрация RemI AI

Файл `demo/index.html` — учебная демонстрация, которую можно скачать и открыть двойным щелчком без установки Python, сервера или базы данных. Сам каталог и пробный тест работают без интернета; для перехода к внешним материалам потребуется интернет.

## Как передать коллеге

1. Отправьте файл `demo/index.html` (один файл, все данные и стили встроены).
2. При желании приложите эту краткую инструкцию или просто напишите, что нужно открыть HTML-файл в браузере.

## Как открыть

1. Сохраните файл на компьютер, например в папку `Загрузки`.
2. Откройте его двойным щелчком мыши — он откроется в браузере по умолчанию.
3. Если браузер не выбрался автоматически, перетащите файл в окно браузера или выберите «Открыть с помощью» → любой современный браузер.

## Важно

- Данные и результаты демонстрационные: вопросы не прошли экспертную проверку.
- Ответы не сохраняются, не отправляются на сервер и не являются реальной оценкой знаний.
- Никаких паролей, реальных студентов или внешних зависимостей для просмотра не требуется.
- Это отдельный демонстрационный файл; основная версия проекта при этом не заменяется и не изменяется.
