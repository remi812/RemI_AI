# Вторая аттестация: RemI AI

Работа посвящена двум задачам: прогнозу результата повторной проверки по предыдущим ответам и поиску учебного раздела по текстовому запросу студента. Подробные объяснения, расчёты и результаты находятся в [блокноте](attestation_2.ipynb) и [отчёте](Отчёт_аттестация_2.pdf).

## Данные и прогноз

Взяты 106 подходящих учебных аккаунтов из временной базы сайта. Все данные тестовые: это не реальные студенты. Часть сценариев повторяется, поэтому результаты нельзя переносить на реальных пользователей без дополнительной проверки.

По числу первоначальных ответов и правильных ответов модель предсказывает, потребуется ли дополнительная проверка после повторного теста. Данные разделены на 63 случая для обучения, 21 для оценки и 22 для прогноза без целевого столбца. Модель и признаки выбирались перекрёстной проверкой на обучении. Выбрана модель ближайших соседей: F1 на оценке — 0,769, полнота — 0,833. Это результат на небольшой учебной выборке.

## Текстовая задача

Готовая многоязычная модель MiniLM помогает искать раздел каталога по описанию запроса студента. На 27 подготовленных учебных запросах она поставила ожидаемый раздел первым в 20 случаях; поиск по словам — в 14. Модель здесь не обучалась; результаты демонстрационные, набор для проверки небольшой.

## Файлы и запуск

- [attestation_2.ipynb](attestation_2.ipynb) — основной блокнот с выполненными ячейками.
- [student_cases.csv](student_cases.csv) — обезличенный учебный набор с ответами для обучения и оценки.
- [forecast_input.csv](forecast_input.csv) и [predictions.csv](predictions.csv) — вход без целевого столбца и прогнозы для 22 случаев.
- [catalog.csv](catalog.csv), [catalog_vectors.npy](catalog_vectors.npy), [neural_questions.json](neural_questions.json) — материалы для проверки текстового поиска.
- [Отчёт](Отчёт_аттестация_2.pdf) — краткое пошаговое описание результатов.

Чтобы повторить вычисления, откройте блокнот в Jupyter или Colab и выполните ячейки по порядку. Нужны Python, pandas, numpy, matplotlib, scikit-learn, onnxruntime и tokenizers. Для текстовой части при первом запуске понадобится интернет: блокнот скачает проверенные файлы готовой модели; можно также указать папку с ними через переменную `REMI_MODEL_DIR`. Расчёты классических моделей используют только файлы из этой папки и не требуют подключения к базе.
