# Проверка источников для пилота по производным

Проверка страниц и описаний проведена 15.11.2026. Это не экспертиза преподавателя, не проверка регистрации, оплаты или просмотра каждого видео целиком. Результат проверки ссылки не меняет `review_status` в PostgreSQL.

| Ссылка, ранее связанная с навыком | Результат |
| --- | --- |
| [OpenStax: Functions and Graphs — введение](https://openstax.org/books/calculus-volume-1/pages/1-introduction) | Страница открылась; это общее введение на английском. |
| [OpenStax: The Derivative as a Function](https://openstax.org/books/calculus-volume-1/pages/3-2-the-derivative-as-a-function) | Страница открылась, посвящена производной; английский язык. |
| [OpenStax: Differentiation Rules](https://openstax.org/books/calculus-volume-1/pages/3-3-differentiation-rules) | Страница открылась, рассматривает правила дифференцирования; английский язык. |
| [Stepik: математический анализ с нуля](https://stepik.org/course/229762/promo) | Название страницы найдено; полное содержание и возможность записи не подтверждены. |
| [Stepik: математический анализ, часть 1](https://stepik.org/course/716/promo) | Название страницы найдено; полное содержание и возможность записи не подтверждены. |
| [УрФУ: математический анализ](https://openedu.ru/course/urfu/CALC/?session=fall_2026) | Описание подходит к теме, но по описанию первая неделя бесплатная, полный доступ платный. Условия следует перепроверять. |

Дополнительно в пилот включены русскоязычные ссылки: [линейное уравнение](https://interneturok.ru/h/biblioteka/algebra/7-klass/lineynoe-uravnenie-s-odnoy-peremennoy/1), [функция и предел](https://teach-in.ru/lecture/09_10_Bikov), [пределы: примеры](https://mathprofi.ru/predely_primery_reshenii.html), [производная — лекция МГУ](https://teach-in.ru/lecture/10_15_Bikov), [правила и примеры производных](https://mathprofi.ru/kak_naiti_proizvodnuju.html). Страницы открылись и их названия или содержание соответствуют указанным темам; доступ к каждому упражнению и предметное качество целиком не подтверждены.

Дополнительная подборка и примечания пока хранятся в `app/derivative_resources.py`, а не записаны как новые ресурсы в PostgreSQL. Для настоящих рекомендаций нужна модерация и полноценный учёт проверок и условий доступа.
