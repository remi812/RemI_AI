# RemI AI

Учебный проект веб-приложения для персонализированного обучения. Идея: студент выбирает дисциплину или тему, проходит адаптивную диагностику, видит карту компетенций и получает маршрут с образовательными материалами.

## Рабочая версия

В каталоге четыре направления. Для отрицательной обратной связи, производных и циклов Python доступны предварительная карта, профиль, адаптивная диагностика, рекомендации внутри подтемы, проверка после изучения и история. Связанные темы Python и ТАУ используют общий банк. Моделирование в каталоге обзорное. Карта выводит цель внизу, сохраняет общие предпосылки и открывает вложенные карты при приближении.

FastAPI выбирает один проверенный вопрос за раз. PostgreSQL хранит профиль, выданную версию, ответы, историю оценок и решения модератора. Предварительная карта доступна до входа. Пороговые правила сохраняются вместе с каждой сессией. Профиль создаётся по псевдониму, почте и паролю. Хеш пароля — scrypt с индивидуальной солью. Токен доступа хранится в HttpOnly-cookie, на сервере сохраняется его хеш. Для HTTPS задайте REMI_HTTPS=1.

Основные документы — [ТЗ](ТЗ_RemI_AI_черновик_0.1.md), [гипотезы диагностики](Правила_диагностики_черновик_0.1.md) и [развёртывание базы](database/README.md). Старый автономный макет в demo/ и интерфейсы /api/pilot/ сохранены для совместимости. Их фиксированные примеры и результаты в localStorage относятся к прежней версии.

## Запуск новой версии на чистой базе

Из корня RemI_AI в PowerShell, при работающем PostgreSQL и настроенном pgpass или переменной PGPASSWORD:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements-model.txt
python database/download_pilot_model.py
$env:PGHOST = '127.0.0.1'
$env:PGPORT = '5432'
$env:PGUSER = 'postgres'
$env:PGDATABASE = 'remi_learning'
createdb remi_learning
python -m app.pilot_admin init
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Если createdb отсутствует в PATH, создайте пустую БД в pgAdmin или используйте полный путь к createdb.exe. Откройте http://127.0.0.1:8000/ . При запуске без модели достаточно requirements.txt. Приложение покажет режим подбора по связям. Загрузка весов нужна один раз, при работе сайта запросы студентов обрабатываются локально.

### Модерация

На обычной установке начальные и повторные вопросы, а также разделы имеют статус pending. Для назначения роли зарегистрируйте профиль преподавателя, узнайте его student_id в таблице remi_project.students и выполните `python -m app.pilot_admin moderator --student-id N`. После входа в маршрут преподавателю доступен кабинет. Он видит версию, ключ, варианты, критерий и фазу вопроса либо курс, раздел, ссылку, описание и проверенные условия доступа. Решение с комментарием попадает в журнал. При допуске материал индексируется. Если модель установлена позже, выполните `python -m app.pilot_admin index` и перезапустите сервер.

### Диагностика и материалы

Параметры пилота REMI_VOTES=2, REMI_DEPTH=3 и REMI_LIMIT=20 задают число согласованных ответов, глубину и лимит показов. После ошибки сервер предпочитает более простое уточнение, после правильного ответа — применение навыка. При двух ошибках проверяются предпосылки. Смешанная пара требует дополнительного задания. Если свидетельств мало, результат остаётся неопределённым. Короткий ответ сравнивается с явно заданным словарём. Уже выданный вопрос исключается для этого профиля, включая незавершённую проверку. При повторном входе можно продолжить текущую сессию.

После диагностики на карте сразу видны следующий навык, его связь с целью, рекомендуемый раздел курса и причина выбора. Если осталось несколько навыков, порядок можно раскрыть в «Дальнейших шагах». Предпосылки идут перед зависящими от них шагами, общий навык встречается один раз. После повторной проверки карта показывает предыдущий и текущий результат и пересчитывает оставшиеся шаги по данным профиля.

Для каждого узла отбираются допущенные русскоязычные разделы с открытым чтением и проверенной связью с навыком. Текст раздела кодируется по названию и описанию, запрос — по цели и навыку. Косинусное сходство используется для сортировки. При пустой выборке сайт сообщает об отсутствии материала. Условия записи, оплаты или таймкоды по странице курса не додумываются.

### Проверка на вымышленных данных

Создайте отдельную пустую базу с именем, оканчивающимся на _demo, задайте PGDATABASE и выполните init. Следующий сценарий имитирует решения модератора исключительно для такого стенда. Он создаёт новые вымышленные профили при каждом запуске. Требуются зависимости из requirements-dev.txt и requirements-model.txt и скачанная модель.

```powershell
$env:PYTHONPATH = (Get-Location).Path
$env:PYTHONUTF8 = '1'
python tests/pilot_acceptance.py control derivatives programming
python tests/retrieval_eval.py
$env:REMI_PILOT_DB_TEST = '1'
$env:REMI_RUN_DB_TESTS = '1'
python -m unittest discover -s tests
```

Для проверки интерфейса запустите сервер на порту 8019, затем `node tests/pilot-browser.cjs` с доступным модулем playwright. REMI_CHROME задаёт путь к Chrome, REMI_HTTP_PORT — порт сайта. Браузерные сценарии проходят обе ветки ТАУ, производные и циклы Python от выбора дисциплины до повторного входа.

На восьми разделах для 12 заранее размеченных русских запросов MiniLM поставила подходящий раздел первым в 10 случаях (MRR 0,903), TF-IDF по словам — в 8 (MRR 0,808). Поиск проверялся по всем разделам без подсказки в виде связи с навыком. Для вопроса про знак рассогласования MiniLM поставила целевой раздел третьим, для наклона касательной — вторым. Разметка составлена разработчиком для проверки поиска. Эффект на знания студентов пока не измерялся.

## Ранее развёрнутый каталог на Windows

Нужны Python 3.10 или новее и запущенный PostgreSQL с базой `RemI_AI` и схемой `remi_project`. Если в базе уже выполнен скрипт 17, примените расширение 18 командой migrate из инструкции к базе. На другом компьютере создайте свою копию базы по инструкции ниже.

Откройте PowerShell в папке проекта и выполните:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe run_local.py
```

Введите пароль пользователя PostgreSQL, когда программа попросит его в терминале: символы не будут отображаться. Пароль остаётся в памяти запущенного процесса и не записывается в проект. Если настроен файл `pgpass`, можно оставить ввод пустым. Затем откройте в браузере `http://127.0.0.1:8000`. Чтобы остановить приложение, нажмите `Ctrl+C` в терминале.

На главной странице выберите дисциплину, затем одну из доступных тем. Для полного каталога и учебных связей нужна заполненная база по инструкции ниже. После обновления кода перезапустите приложение, чтобы загрузить изменения сервера.

По умолчанию подключение идёт к `127.0.0.1:5432`, базе `RemI_AI`, пользователю `postgres`. При других настройках задайте переменные окружения `PGHOST`, `PGPORT`, `PGDATABASE`, `PGUSER` перед запуском; пароль также может передаваться через `PGPASSWORD` или `pgpass`. Не добавляйте пароли в GitHub. В дальнейшем для приложения нужно создать отдельного пользователя базы с ограниченными правами.

При ошибке загрузки убедитесь, что PostgreSQL работает, база и схема созданы и данные подключения верны. Страница не подменяет данные базы заранее сохранённым списком.

## Создание базы данных

Репозиторий содержит файлы проекта и SQL-скрипты. Чтобы развернуть базу, установите PostgreSQL, создайте локальную базу и следуйте [инструкции к базе](database/README.md). Данные, добавленные после выполнения скриптов, хранятся в локальной базе.

Для новой пустой базы учебный набор можно создать, выполнив в Query Tool файлы из `database` в порядке: `01`, `03`, `05`, `06`, `07`, `08`, `09`, `10`, `12`, затем `14_студенты_аттестация.sql` и `17_каталог_курсов.sql`. Файл 17 переводит каталог на четыре активных направления и добавляет материалы; старую дисциплину сохраняет для истории. Представление `14_аттестация_VIEW.sql` и файлы с примерами запросов подключаются отдельно по необходимости. Скрипты создания схем предназначены для однократного запуска; не выполняйте их повторно в уже заполненной базе.
