# RemI AI

Учебный проект веб-приложения для персонализированного обучения. Идея: студент выбирает дисциплину или тему, проходит адаптивную диагностику, видит карту компетенций и получает маршрут с образовательными материалами.

## Что уже есть

- Концепция и [черновик ТЗ](ТЗ_RemI_AI_черновик_0.1.md).
- [Черновые правила диагностики](Правила_диагностики_черновик_0.1.md): пороги пока не утверждены и алгоритм не реализован.
- [SQL-схема и учебные данные PostgreSQL](database/README.md): дисциплины, компетенции, вопросы, результаты и примеры маршрутов. Учебные пользователи вымышлены.
- [Исследование OULAD](research/oulad/Анализ_OULAD_для_RemI_AI.md) и отдельные сводные данные для PostgreSQL.

Самого веб-приложения, входа пользователей и автоматического построения маршрутов пока нет. Вопросы и материалы требуют экспертной проверки перед реальной диагностикой.

## Как работать вместе

1. Клонируйте репозиторий командой `git clone <адрес-репозитория>` или через GitHub Desktop.
2. Перед началом работы получайте последние изменения: `git pull`.
3. Вносите изменения, сохраняйте коммит и отправляйте его через `git push`. Чтобы не перезаписывать чужую работу, договаривайтесь, кто изменяет один и тот же файл; для отдельных задач можно использовать отдельные ветки.
4. Секреты и пароли в репозиторий не добавляются. Для PostgreSQL у каждого разработчика могут быть свои локальные настройки.

GitHub хранит файлы проекта и SQL-скрипты, но не синхронизирует работающую базу PostgreSQL. Чтобы развернуть копию базы на другом компьютере, установите PostgreSQL, создайте локальную базу и следуйте [инструкции к базе](database/README.md). Данные, добавленные в одну локальную базу после запуска скриптов, автоматически не появятся у другого разработчика.

Для новой пустой базы учебный набор можно создать, выполнив в Query Tool файлы из `database` в порядке: `01`, `03`, `05`, `06`, `07`, `08`, `09`, `10`, `12`, затем `14_студенты_аттестация.sql`. Представление `14_аттестация_VIEW.sql` и файлы с примерами запросов подключаются отдельно по необходимости. Исследовательская схема OULAD устанавливается отдельно из `research/oulad/oulad_research.sql`. Скрипты создания схем предназначены для однократного запуска; не выполняйте их повторно в уже заполненной базе.
